LosslessStudio installation guide
=================================

Requirements
An Apple silicon Mac running macOS 26 or later. The app includes FFmpeg,
ffprobe, and ImageMagick. You do not need to install Homebrew.

Install from a disk image
1. Open the LosslessStudio disk image (.dmg).
2. Drag LosslessStudio.app to the Applications shortcut in the disk image.
3. Open LosslessStudio from Applications, then eject the disk image.

Install from a ZIP
1. Double-click the ZIP to extract LosslessStudio.app.
2. Move the app to Applications and open it there.

Check the publisher and download source before opening an ad-hoc signed
build. The candidate uses a local code signature and has no Apple
notarization. If macOS asks you to verify the developer, follow Apple's
instructions at https://support.apple.com/en-us/102445.

Language
The app follows your macOS language preferences and supports English and
Traditional Chinese. To set the language for this app, open System Settings,
then General > Language & Region > Applications. Add LosslessStudio, choose
the language, and relaunch the app.

Usage and licenses
See USER_GUIDE.en.md for conversion modes and verification. License terms
and source information are included in the app's Resources folder and on
the disk image. See LICENSE-FFMPEG.txt, LICENSE-IMAGEMAGICK.txt, and licenses/.
